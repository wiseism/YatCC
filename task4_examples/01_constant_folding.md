# 常量折叠 (Constant Folding)

## 概述

常量折叠是一种编译优化技术，它在编译时计算常量表达式的值，而不是在运行时计算。这样可以减少运行时的计算开销，提高程序性能。

## 原理

当编译器遇到一个表达式，其所有操作数都是编译时常量时，可以在编译阶段直接计算出结果，用计算结果替换整个表达式。

### 示例

**优化前：**
```c
int x = 3 + 5;      // 运行时计算
int y = 10 - 2;     // 运行时计算  
int z = 4 * 6;      // 运行时计算
```

**优化后：**
```c
int x = 8;           // 编译时计算完成
int y = 8;           // 编译时计算完成
int z = 24;          // 编译时计算完成
```

## 优化条件

常量折叠需要满足以下条件：
1. 所有操作数都是编译时常量
2. 运算结果在编译时可以确定
3. 运算没有副作用（如除零检查等）

## 支持的运算

常见的常量折叠运算包括：
- **算术运算**：加法、减法、乘法、除法、取模
- **位运算**：与、或、异或、非、左移、右移
- **逻辑运算**：与、或、非
- **比较运算**：等于、不等于、小于、大于等

## 实现步骤

1. **遍历指令**：遍历模块中的所有函数、基本块和指令
2. **识别可折叠指令**：检查指令是否为二元运算且操作数都是常量
3. **计算结果**：根据操作符类型执行相应的常量运算
4. **替换使用**：用计算出的常量结果替换原指令的所有使用
5. **删除原指令**：移除已被替换的指令

## 优势

1. **性能提升**：减少运行时计算，加快程序执行速度
2. **代码简化**：减少指令数量，降低代码复杂度
3. **后续优化**：为其他优化（如死代码消除）创造条件
4. **零成本**：编译时优化，运行时无额外开销

## 局限性

1. **仅限常量**：只能处理编译时常量，不能处理运行时值
2. **溢出处理**：需要注意整数溢出问题
3. **浮点精度**：浮点运算的精度和舍入需要特殊处理
4. **除零检查**：某些语言需要保留除零检查

## 在LLVM中的实现

在LLVM中，常量折叠通过Pass实现：

```cpp
class ConstantFolding : public llvm::PassInfoMixin<ConstantFolding> {
public:
  llvm::PreservedAnalyses run(llvm::Module& mod, 
                              llvm::ModuleAnalysisManager& mam);
};
```

LLVM提供了丰富的常量操作API：
- `ConstantInt::get()` - 创建整数常量
- `ConstantFP::get()` - 创建浮点常量
- `ConstantExpr::getAdd()` - 创建加法常量表达式
- 等等...

## 总结

常量折叠是最基础也最重要的编译优化之一，它简单高效，几乎在所有编译器中都有实现。理解常量折叠有助于深入理解编译优化的基本原理。
